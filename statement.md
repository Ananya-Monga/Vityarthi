# Project Statement

## Project title
Library Management System Using Python and SQLite

## Problem statement
Manual library records can be difficult to maintain consistently. Book availability, member details, issue/return dates, and overdue items need to be tracked in one place. This project provides a small local system to maintain these records and reduce common inventory and record-keeping errors.

## Scope
The project supports book and member record management, issuing and returning books, inventory updates, active-loan listing, overdue reporting, and a summary dashboard. It is a single-user, command-line application intended for learning and demonstration. Online access, fine payment, authentication, and multi-branch operation are outside the current scope.

## Target users
- Students learning Python, modular programming, SQL, and CRUD operations
- Library assistants managing a small local collection
- Faculty evaluating a basic database-backed application

## High-level features
1. Book catalogue CRUD and search
2. Member registration and maintenance
3. Issue/return workflow with stock validation
4. Active-loan and overdue reports
5. Dashboard summary
6. SQLite persistence and automated tests
